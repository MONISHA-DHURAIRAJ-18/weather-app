# 🌤️ Weather App

A simple and interactive **Weather Application** built using **HTML, CSS, JavaScript, and the OpenWeatherMap API**.

The application allows users to search for weather information by city, use their current location, switch between **°C and °F**, and view a **3-day weather forecast**.

## ✨ Features

* 🌍 Search weather by city name
* 📍 Get weather using current location
* 🌡️ Toggle between Celsius and Fahrenheit
* 🌤️ Display current weather conditions
* 💧 Show humidity
* 💨 Show wind speed
* 🌡️ Display "Feels Like" temperature
* 🕐 Show local time
* 📅 3-day weather forecast
* 🎨 Dynamic background based on weather conditions
* 🔄 Automatically refresh weather data every 15 minutes
* ❌ Displays user-friendly error messages

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API integration
* **OpenWeatherMap API** – Weather and forecast data

## 🔑 API Used

This project uses the **OpenWeatherMap API** to retrieve real-time weather information and forecast data.

You will need an API key from OpenWeatherMap to run the application.
